# Correo Norma

Web personal para gestionar el correo sobre Gmail: bandeja por prioridades («vaciar bandeja»), borradores listos para dar el OK, delegar, posponer, seguimiento y búsqueda.

- **No contiene ningún correo ni dato personal.** La página se conecta a Gmail directamente desde el navegador de quien inicia sesión (OAuth de Google) y solo funciona para las cuentas autorizadas en el proyecto de Google Cloud.
- Web estática: `index.html`, `styles.css`, `app.js`, `config.js`.
